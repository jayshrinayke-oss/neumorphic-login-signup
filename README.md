# Neumorphic Login & Signup Form

A responsive Login and Signup form built using HTML, CSS, and JavaScript with a soft neumorphic UI design.

## Features

- Login and Signup forms with sliding animation
- Responsive layout for mobile and desktop
- Form validation
- Password show/hide toggle
- Password strength indicator
- Forgot Password popup
- Remember Me checkbox
- Google and GitHub social login buttons (UI demo)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts — Nunito
- Font Awesome

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.

## Note

This is a frontend demo project. Login, signup, and social login do not use real authentication or create actual user accounts.
